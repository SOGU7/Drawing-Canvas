# 🖌️ Drawing Canvas in C++ with OpenGL

An interactive drawing application built using **C++** and **OpenGL (GLUT)** that allows users to create scenes with trees, clouds, birds, sun, and more using a graphical palette-based interface. Designed as a beginner-friendly introduction to computer graphics and OpenGL programming.

---

## 🚀 Features

* 🎨 **Palette-based Drawing Interface** – Choose from various drawable objects like:

  * Trees 🌳
  * Clouds ☁️
  * Birds 🐦
  * Sun ☀️
  * Water, Flowers, Houses, etc.
* 🖱️ **Mouse Interaction** – Click anywhere on the canvas to place the selected object.
* 🫮 **Modular Drawing Functions** – Clean and reusable code for each graphical component.
* 🔄 **Real-Time Rendering** – Uses OpenGL's double buffering for smooth visuals.
* 🪿 **Full-screen Window Support** – Adapts to different resolutions with coordinate conversion helpers.

## 🛠️ Setup Instructions

### 🔧 Prerequisites

* Code::Blocks IDE (or any C++ IDE with OpenGL/GLUT support)
* OpenGL and GLUT libraries installed

### 🏗️ Build & Run

1. Clone the repository:

   ```bash
   git clone https://github.com/ShougataDas/Drawing-Canvas.git
   ```
2. Open `Drawing Canvas.cbp` in Code::Blocks.
3. Build the project (Build → Build).
4. Run the executable (Build → Run or press `F9`).

> You can also run the prebuilt binary available in `bin/Debug/`.
